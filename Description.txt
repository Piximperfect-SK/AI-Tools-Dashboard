Project structure map:
- index.html: Thin HTML shell generated by Vite that injects the bundled JS/CSS and provides the `<div id="root">` target.
- package.json: Defines scripts (`dev`, `build`, `preview`), dependencies, and metadata for the dashboard.
- package-lock.json: Reproducible dependency tree from `npm install`.
- README.md: Runbook covering install/run/build commands and the Tailwind/React/Vite stack.
- Attributions.md: Credits for the icons/illustrations used in the Figma-inspired UI.
- tsconfig.json: Enables JSX/strict checking and mirrors the `vite.config.ts` aliases for editors.
- vite.config.ts: Sets up `@vitejs/plugin-react-swc`, path aliases, build targets, and dev-server options.
- node_modules/: Generated dependency tree matching the lockfile (do not edit manually).

src/ entry points:
- main.tsx: Bootstraps React by rendering `<App />` into `#root` and importing `index.css`.
- App.tsx: Minimal wrapper that renders `AIToolsDashboard`.
- index.css: Tailwind base layer plus typography/background resets.
- styles/globals.css: Supplemental global tokens, scrollbar tweaks, and colors layered on the Tailwind base.

src/components/:
- AIToolsDashboard.tsx: Drives the UI—tool dataset, filters, hero copy, pagination, empty states, footer CTA, and orchestration of `filteredTools` passed to cards.
- AIToolCard.tsx: Renders each tool card with gradient header, badges, feature list, pricing, explore button, hover/favorite state, and `motion` entrances.
- figma/ImageWithFallback.tsx: `<img>` wrapper that drops into a styled fallback rectangle when a logo cannot load.

src/components/ui/ (`~/components/ui` wrappers):
- accordion.tsx: Stacked accordion with chevrons and padding that wraps the Radix primitive.
- alert.tsx: Alert panels for success, warning, or destructive states.
- alert-dialog.tsx: Confirmation dialog composed from Radix `AlertDialog` items with consistent overlay classes.
- aspect-ratio.tsx: Container enforcing CSS `aspect-ratio` with dashboard spacing.
- avatar.tsx: Avatar primitive with image, fallback, and ring styling.
- badge.tsx: Tiny status chip with variant colors.
- breadcrumb.tsx: Breadcrumb list with chevrons for navigation context.
- button.tsx: Shared button primitive with variants (primary, ghost, icon) plus focus rings.
- calendar.tsx: Date picker layout with navigation controls.
- card.tsx: Card shell that pulls in padding, border-radius, and footer slots.
- carousel.tsx: Slider wrapper handling arrows/dots with smooth motion.
- chart.tsx: Victory chart wrapper standardizing axes and colors.
- checkbox.tsx: Checkbox + label with aligned spacing and focus rings.
- collapsible.tsx: Disclosure component that animates height changes.
- command.tsx: Command-palette scaffold (search input + list) for filtered actions.
- context-menu.tsx: Floating context menu with arrows and focus styling.
- dialog.tsx: Dialog overlay with consistent gradients and backdrops.
- drawer.tsx: Sheet-style slide-over powered by Radix `Sheet`.
- dropdown-menu.tsx: Compact dropdown with arrowed overlay and padded items.
- form.tsx: Form helpers (`FormField`, `FormItem`, `FormMessage`) that lock spacing/validation styling.
- hover-card.tsx: Hover-trigger container with drop shadow for previews/tooltips.
- input.tsx: Text input with ghost/solid variants and accessible focus.
- input-otp.tsx: Row of equal-width OTP cells with auto-advance focus logic.
- label.tsx: Label helper to keep font weight/spacing consistent.
- menubar.tsx: Horizontal menubar layout with dropdown triggers.
- navigation-menu.tsx: Tabs/panels layout for navigation menus.
- pagination.tsx: Prev/next buttons and numbered chips that signal the current page.
- popover.tsx: Popover container with arrow, offset, and drop shadow.
- progress.tsx: Linear progress bar with track + indicator.
- radio-group.tsx: Radio group container enforcing alignment and focus styles.
- resizable.tsx: Panel with drag handles and size clamps for adjustable components.
- scroll-area.tsx: Scrollable region that hides native scrollbars while staying accessible.
- select.tsx: Dropdown select with trigger/content layout matching Radix’s API.
- separator.tsx: Divider for horizontal/vertical layouts.
- sheet.tsx: Top/bottom drawer with heavier overlay styles.
- sidebar.tsx: Sidebar container used for nav lanes or grouped actions.
- skeleton.tsx: Loading skeleton blocks for pending content.
- slider.tsx: Range slider with thumb/track styling.
- sonner.tsx: Toast container built on `sonner` for branded notifications.
- switch.tsx: Toggle switch with transition and fill states.
- table.tsx: Table layout helpers for rows, header, and cells.
- tabs.tsx: Tabs primitive with underline indicator and animated panels.
- textarea.tsx: Multi-line input with fixed padding and disabled resize.
- toggle.tsx: Toggle-style button that reflects pressed states.
- toggle-group.tsx: Grouped toggles where one selection stays active.
- tooltip.tsx: Tooltip wrapper with arrow, delay, and drop shadow.
- use-mobile.ts: Hook that tracks viewport width to toggle mobile styling.
- utils.ts: Shared helpers (`cn`, `buttonVariants`, etc.) consumed by every primitive above.

Additional notes:
- There is no `src/utils/` directory in this commit; shared helpers live inside `components/ui/utils.ts` and the dashboard files themselves.
- Run `npm run dev` to start Vite on port 5173, `npm run build` to emit production assets, and `npm run preview` to serve the build output.
